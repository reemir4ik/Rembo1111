# AIBuyer Creative Engine 🎨

Генератор рекламных креативов для Facebook Ads с AI.

![Demo](https://img.shields.io/badge/Status-Live-success)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🚀 Демо

**Работающий сайт:** https://reemir4ik.github.io/Rembo1111/

## ✨ Возможности

- ✅ Генерация текстов для рекламы (AI-powered)
- ✅ Создание визуальных баннеров 1080×1080
- ✅ 5 разных шаблонов дизайна
- ✅ Полная настройка цветов
- ✅ 8 тонов коммуникации
- ✅ Скачивание HTML-баннеров
- ✅ Копирование текстов

## 🎯 Как пользоваться

1. Заполни форму (ниша, бренд, оффер, УТП)
2. Выбери тон коммуникации
3. Выбери шаблон дизайна
4. Настрой цвета (или оставь по умолчанию)
5. Нажми **СГЕНЕРИРОВАТЬ**
6. Получи 3 готовых баннера + тексты

## 🛠 Технологии

- **Frontend:** HTML + CSS + Vanilla JS
- **Backend:** Vercel Serverless Functions
- **AI:** OpenAI GPT-4o-mini
- **Hosting:** GitHub Pages + Vercel

## 📊 Статистика

- **Стоимость генерации:** ~$0.0004 (меньше цента)
- **Скорость:** 5-10 секунд
- **Форматы экспорта:** HTML (можно открыть в браузере)
